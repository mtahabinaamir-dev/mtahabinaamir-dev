## The journey — small to big

### [huffman-compressor](https://github.com/mtahabinaamir-dev/huffman-compressor) — C, one file
A Huffman file compressor in standard C. 493 lines, one file, no libraries: frequency table, tree, bit-level output, and a CRC32 check so a damaged file fails loudly instead of decoding wrong.
C

### [expense-tracker](https://github.com/mtahabinaamir-dev/expense-tracker) — Java, desktop
A personal expense tracker in JavaFX: add, edit, and filter expenses, month totals, per-category breakdown with a pie chart. Data stays local in a CSV file.
Java · JavaFX

### [booknook](https://github.com/mtahabinaamir-dev/booknook) — PHP, full-stack web app
A small online bookstore in plain PHP + PDO: catalog, search, cart, cash-on-delivery checkout, admin panel.
**[▶ Live demo](https://booknook-8pn9.onrender.com)** · PHP · PDO

### [histomotion](https://github.com/mtahabinaamir-dev/histomotion) — React, interactive site
History you scroll through: six story-driven journeys, 52 fact-checked milestones, GSAP scroll-slide journey, animated timelines, full-text search.
**[▶ Live demo](https://histomotion.onrender.com)** · React · Vite · GSAP

### [Prompt2Page](https://github.com/mtahabinaamir-dev/Prompt2Page) — Node.js, AI product
An AI website builder, co-created with Afnan Siddiqui: describe a site in plain language, watch it build live, refine it with chat commands, export it. 300+ automated tests, CI, Docker, security pass.
**[▶ Live demo](https://prompt2page-z0vz.onrender.com)** · Node.js · Express · JavaScript
